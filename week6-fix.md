# Исправления Week 6 (week6-fixes.md)

Перед переходом к Week 7 были исправлены три критических сценария в проекте `todo`.

## 1. Стартовые задачи загружаются по корректному локальному URL

- **Причина:** На GitHub Pages относительный путь `data/tasks.json` без ведущей точки мог разрешаться относительно корня домена, а не текущей директории `todo/`, что приводило к ошибке 404.
- **Измененные файлы:** `todo/js/api.js`, `todo/js/main.js` (изменен путь на `./data/tasks.json`).
- **Фактическая проверка на GitHub Pages:** LocalStorage очищен. Страница обновлена. В списке отображаются ровно 3 стартовые задачи из `data/tasks.json`. Ошибок 404 в консоли нет.
- **Ссылка на коммит:** [https://github.com/quazystr/frontend-week6/commit/12598005bfc55d964a2d99fdd5ffd4d13064b2d5]

## 2. TimeoutError и AbortError обрабатываются раздельно

- **Причина:** Ранее `AbortSignal.timeout()` и ручной `AbortController.abort()` могли попадать под одну проверку, из-за чего таймаут не показывался пользователю, либо отмена устаревшего запроса (например, при быстром вводе) ошибочно показывалась как ошибка сети.
- **Измененные файлы:** `todo/js/api.js` (добавлены раздельные проверки `error.name === 'TimeoutError'` и `error.name === 'AbortError'`). Функция `getNetworkErrorMessage` возвращает `null` для `'ABORT'`, чтобы скрыть сообщение, и текст для `'TIMEOUT'`.
- **Фактическая проверка на GitHub Pages:**
  1. Включен Slow 3G, LocalStorage очищен. Через 5 секунд появляется алерт "Сервер не ответил вовремя".
  2. При быстром переключении фильтров или импорте (с искусственной задержкой) устаревшие запросы отменяются, но красные алерты об ошибке не появляются.
- **Ссылка на коммит:** [https://github.com/quazystr/frontend-week6/commit/11b85b76847a53a002df60ed16260d762a7df178]

## 3. Ошибка стартовой загрузки лежит в состоянии и дает рабочую кнопку «Повторить»

- **Причина:** В блоке `catch` функции `fetchInitialTasks` статус ранее сбрасывался в `'idle'`. Функция `renderStatus` скрывает блок `.status` для статуса `'idle'`, поэтому пользователь не видел ни текста ошибки, ни кнопки «Повторить».
- **Измененные файлы:** `todo/js/main.js` (в `catch` блока `fetchInitialTasks` статус явно устанавливается в `'error'` с сообщением).
- **Фактическая проверка на GitHub Pages:** Включен режим Offline, LocalStorage очищен, страница обновлена. Отображается блок `status--error` с текстом "Нет соединения с сервером" и активная кнопка «Повторить». При нажатии на кнопку (после выключения Offline) загрузка успешно повторяется.
- **Ссылка на коммит:** [https://github.com/quazystr/frontend-week6/commit/eef6bbfd4468882607e2443311e345bfd5afbf24]
