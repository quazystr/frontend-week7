Функция только один раз

Функция createOnce(fn) создаёт обёртку, которая вызывает fn только при первом вызове. Все последующие вызовы возвращают сохранённый результат без повторного выполнения fn.

Обёртка вызвана: 0 раз
Реальных вызовов fn: 0
Обратите внимание: счётчик "Реальных вызовов fn" увеличивается только при первом нажатии. Все последующие вызовы возвращают сохранённый результат.
